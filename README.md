I am a machine learning practitioner and software engineer based in Canada, focused on **building and training deep learning architectures from first principles**. My work spans causal transformers, computer vision, statistical predictive modeling, and scientific simulations.

---

## 🛠️ Core Engineering Capabilities

### 🧠 1. Large Language Models & Transformer Architectures
- **First-Principles Modeling**: Implementing transformer blocks from scratch in PyTorch—multi-head self-attention, rotary positional embeddings (RoPE), RMSNorm, and KV-caching.
- **Model Training & Adaptation**: Training, fine-tuning, and evaluating lightweight language models (e.g., TinyLlama, character/token autoregressive language models).
- **Inference Optimization**: Building efficient greedy/top-$p$/temperature sampling loops, custom tokenization pipelines, and memory-aware batching.

### 👁️ 2. Deep Learning & Computer Vision
- **PyTorch Foundations**: Writing modular training loops from zero—custom datasets, custom loss functions, learning rate schedules, and gradient clipping.
- **Representation Learning**: Developing custom convolutional networks (CNNs), residual backbones, transfer learning workflows, and multi-class classification pipelines.

### 📊 3. Applied Machine Learning & Statistical Modeling
- **High-Performance Ensembles**: Advanced feature engineering, feature interaction tracking, and Quantile Gradient Boosting (LightGBM / XGBoost).
- **Uncertainty & Safety**: Implementing Distribution-Free Conformal Prediction (EnbPI) to provide mathematical coverage guarantees under data distribution shifts.
- **Handling Asymmetry**: Techniques for heavily imbalanced anomaly detection and time-series feature lagging.

### ⚛️ 4. Scientific Simulation & Dynamical Systems
- **Numerical Physics**: Solving continuous differential equations for physical systems (atomic orbital visualization, thermal envelope dynamics).
- **Physical Digital Twins**: Coupling electrochemistry (Peukert non-linear battery degradation), thermal physics, and discrete state machines with AI controllers.

### ⚙️ 5. Software Engineering Rigor & MLOps
- **Formal Invariant Verification**: Using property-based testing (`Hypothesis`, `pytest`) to verify thousands of randomized state permutations against mathematical safety lattices.
- **Interactive Analytics**: Crafting enterprise-grade reactive dashboards using Streamlit and Plotly.
